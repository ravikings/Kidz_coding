## ▶️ How to Start (2 Ways)

### Option 1 — Play online (easiest)
Just open **[ravikings.github.io/Kidz_coding](https://ravikings.github.io/Kidz_coding/)**
in any modern browser (Chrome, Edge, Safari, or Firefox). That's it.

### Option 2 — Run it offline on your own computer
1. Download or clone this repository.
2. Double-click **`kidz_coding/index.html`**.
3. It opens right in your browser — no internet required.

```bash
git clone https://github.com/ravikings/Kidz_coding.git
cd Kidz_coding
open kidz_coding/index.html   # Windows: just double-click the file
```

## 🛠️ For Developers

Kidz Java Coding Lab is a single, dependency-free `index.html`:

- Pure HTML, CSS, and vanilla JavaScript — no build step, no frameworks.
- A tiny client-side interpreter simulates core Java (`println`, variables,
  arithmetic, string concatenation, basic `if`).
- Progress persists via `localStorage`.
- Automatically deployed to **GitHub Pages** on every push to `main` via GitHub
  Actions (see [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)).

Contributions that add levels, improve the simulator, or sharpen the kid-friendly
UX are welcome.
